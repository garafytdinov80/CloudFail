# Локальный конфигуратор LED-экрана для Bitrix

В репозитории добавлен компонент `custom:ledsi.configurator`. Он полностью работает внутри сайта Bitrix и не загружает внешний сайт `https://led-si.com` через `iframe`.

PHP-файлы компонента адаптированы под PHP 8: используется строгая типизация, проверка числовых параметров через `is_numeric`, безопасные значения по умолчанию и явное приведение значений перед выводом в шаблоне.

Компонент рассчитывает ориентировочные параметры LED-экрана:

- фактический размер с учётом выбранного кабинета;
- площадь экрана;
- разрешение по выбранному шагу пикселя;
- количество кабинетов по ширине, высоте и всего;
- соотношение сторон;
- среднее энергопотребление.

## Установка

1. Скопируйте каталог `local/components/custom/ledsi.configurator` в корень сайта Bitrix, сохранив путь:

   ```text
   /local/components/custom/ledsi.configurator
   ```

2. На нужной странице Bitrix подключите компонент:

   ```php
   <?php
   $APPLICATION->IncludeComponent(
       'custom:ledsi.configurator',
       '',
       [
           'TITLE' => 'Конфигуратор LED-экрана',
           'DESCRIPTION' => 'Рассчитайте ориентировочные параметры LED-экрана.',
           'DEFAULT_WIDTH' => '3',
           'DEFAULT_HEIGHT' => '2',
           'DEFAULT_PITCH' => '2.5',
           'DEFAULT_CABINET_WIDTH' => '500',
           'DEFAULT_CABINET_HEIGHT' => '500',
           'DEFAULT_POWER' => '350',
           'SHOW_LEAD_FORM' => 'Y',
           'LEAD_BUTTON_TEXT' => 'Отправить расчёт менеджеру',
           'CSS_CLASS' => '',
       ]
   );
   ?>
   ```

3. Если страница редактируется через визуальный редактор Bitrix, компонент будет доступен в разделе **Пользовательские компоненты** под названием **Локальный конфигуратор LED-экрана**.

## Параметры

- `TITLE` — заголовок блока.
- `DESCRIPTION` — текст под заголовком.
- `DEFAULT_WIDTH` — стартовая ширина экрана в метрах.
- `DEFAULT_HEIGHT` — стартовая высота экрана в метрах.
- `DEFAULT_PITCH` — стартовый шаг пикселя в миллиметрах.
- `DEFAULT_CABINET_WIDTH` — стартовая ширина кабинета в миллиметрах.
- `DEFAULT_CABINET_HEIGHT` — стартовая высота кабинета в миллиметрах.
- `DEFAULT_POWER` — среднее потребление в ваттах на квадратный метр.
- `SHOW_LEAD_FORM` — показывает кнопку копирования расчёта для передачи менеджеру.
- `LEAD_BUTTON_TEXT` — текст кнопки копирования расчёта.
- `CSS_CLASS` — дополнительный CSS-класс контейнера для точечной стилизации.

## Как расширять

Сейчас расчёт выполняется локально в `templates/.default/script.js`. Если нужно добавить точные коммерческие параметры, их лучше хранить в инфоблоке Bitrix или Highload-блоке и передавать в шаблон через `component.php`:

- серии экранов;
- цены;
- тип монтажа;
- indoor/outdoor;
- яркость;
- вес кабинета;
- максимальное потребление;
- отправку заявки в CRM или почтовое событие Bitrix.
